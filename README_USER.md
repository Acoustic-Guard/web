## 1. Що таке Acoustic Guard

Acoustic Guard — це система розподіленого міського акустичного моніторингу. Вона в реальному часі відстежує акустичну обстановку в місті за допомогою мережі сенсорів та відображає інформацію на інтерактивній карті.

Як звичайний користувач ви можете:
- Бачити теплову карту активних загроз у місті
- Переглядати карту рівнів шуму по районах
- Дізнатись рівень шуму саме у вашому районі
- Отримувати сповіщення якщо загроза виявлена поруч з вами

> Для входу не потрібна реєстрація — система доступна одразу після відкриття.

## 2. Встановлення та запуск системи

> Цей розділ призначений для технічних спеціалістів, які розгортають систему. Якщо система вже запущена — переходьте одразу до розділу 3.

---

### Що потрібно перед початком

Переконайтесь що на вашому комп'ютері встановлено:

| Програма | Версія | Навіщо |
|---|---|---|
| Docker | v24.0.0+ | Запуск всіх сервісів системи |
| Docker Compose | v2.20.0+ | Оркестрація контейнерів |

Технічні вимоги до комп'ютера:
- **Оперативна пам'ять:** мінімум 8 ГБ вільної RAM
- **Місце на диску:** мінімум 20 ГБ вільного простору

---

### Крок 1 — Завантажте репозиторій

Відкрийте термінал і виконайте:

```bash
git clone <repository-url>
cd acoustic_guard/infra
```

---

### Крок 2 — Запустіть систему

```bash
docker compose up -d --build
```

Ця команда автоматично:
- Завантажить та зберуть всі необхідні компоненти
- Запустить базу даних, брокер повідомлень та ML-класифікатор
- Підніме 13 симульованих сенсорів з тестовими акустичними даними

> Перший запуск може тривати **5–10 хвилин** — Docker завантажує образи та збирає сервіси.

---

### Крок 3 — Перевірте що все працює

```bash
docker compose ps
```

Всі контейнери повинні мати статус `running` або `healthy`. Якщо якийсь не запустився — перегляньте його логи:

```bash
docker compose logs -f <назва-сервісу>
```

---

### Крок 4 — Відкрийте інтерфейс

Після успішного запуску відкрийте браузер та перейдіть за адресою:

```
http://localhost:3000
```

Система готова до роботи. Ви одразу побачите інтерактивну карту з даними від симульованих сенсорів.

---

### Зупинка системи

Щоб зупинити систему (дані зберігаються):

```bash
docker compose down
```

Щоб зупинити та **повністю видалити всі дані** (база, черги, логи):

```bash
docker compose down -v
```

## 3. Загальний вигляд інтерфейсу

![Загальний вигляд — теплова карта активних загроз](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20173136.png)

Інтерфейс складається з:

- **Бічна панель зліва** — логотип системи та кнопка входу для операторів (замок внизу)
- **Верхній заголовок** — назва системи Acoustic Guard та підзаголовок
- **Інтерактивна карта** — займає весь основний простір
- **Кнопки шарів** (лівий верхній кут карти) — перемикання між тепловою картою та картою шуму
- **Кнопки керування** (правий верхній кут карти) — збільшення, зменшення, тема, локація
- **Легенда** (лівий нижній кут карти) — пояснення кольорів
- **Панель вашого району** (правий нижній кут) — рівень шуму поруч з вами

## 4. Теплова карта загроз

![Теплова карта загроз по Києву](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20173103.png)

Кнопка **«Heatmap»** у верхньому лівому куті карти (синя коли активна).

Теплова карта показує зони де зафіксовані акустичні загрози. Чим яскравіший та більший колір — тим більше загроз в цій зоні і тим вища їх інтенсивність.

### Кольорова шкала

| Колір | Значення |
|-------|---------|
| 🔵 Синій | Слабкий сигнал, поодинокі фіксації |
| 🟢 Зелений | Помірна активність |
| 🟡 Жовтий | Підвищена активність |
| 🟠 Оранжевий | Висока активність |
| 🔴 Червоний | Критична зона, максимальна інтенсивність |

> Теплова карта оновлюється автоматично при появі нових інцидентів через WebSocket з'єднання — перезавантажувати сторінку не потрібно.

## 5. Карта шуму

![Гексагональна карта шуму Дарницького району](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20173113.png)

Кнопка **«Noise map»** у верхньому лівому куті карти (фіолетова коли активна).

Карта шуму відображає акустичну обстановку по Дарницькому району у вигляді гексагональної сітки (бджолині соти). Кожен шестикутник — це зона ~450 метрів, зафарбована відповідно до рівня шуму в ній.

### Кольорова шкала рівнів шуму

| Колір | Рівень шуму | Опис |
|-------|------------|------|
| 🟢 Зелений | < 45 дБ | Тиша, спокійна зона |
| 🔵 Синій | 45–55 дБ | Норма для міста |
| 🟡 Жовтий | 55–65 дБ | Помітний шум |
| 🟠 Оранжевий | 65–75 дБ | Гучно |
| 🔴 Червоний | > 75 дБ | Небезпечний рівень шуму |

Кольори між зонами плавно переходять один в одний — якщо поруч є тиха і гучна зони, між ними будуть проміжні відтінки.

Дані оновлюються кожні **30 секунд**.

> Натисніть кнопку **«Heatmap»** або **«Noise map»** ще раз щоб вимкнути відповідний шар.

## 6. Керування картою

![Кнопки керування картою — зум, тема, локація](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20173127.png)

Вертикальна група кнопок у **правому верхньому куті**:

| Кнопка | Дія |
|--------|-----|
| **🔍+** | Збільшити масштаб карти |
| **🔍−** | Зменшити масштаб карти |
| **☀ / 🌙** | Перемикання між темною і світлою темою карти |
| **⊕** | Визначити моє місцезнаходження |

### Темна та світла теми карти

**Темна тема** — використовується за замовчуванням. Оптимальна для перегляду теплової карти та нічного використання.

**Світла тема** — стандартна OpenStreetMap підкладка. Краще підходить для детального перегляду вулиць та районів.

![Карта у світлій темі з маркерами інцидентів та сповіщенням](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20173158.png)

## 7. Моя локація та рівень шуму поруч

### Крок 1 — Надайте доступ до геолокації

Натисніть кнопку **⊕** (іконка геолокації) у правому верхньому куті карти.

![Кнопка геолокації та панель «Your area»](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20173127.png)

Браузер запитає дозвіл на визначення вашого місцезнаходження. Натисніть **«Дозволити»**.

> Якщо ви випадково натиснули «Заблокувати» — зайдіть у налаштування браузера → Конфіденційність → Геолокація → дозвольте для цього сайту.

### Крок 2 — Маячок на карті

Після надання доступу на карті з'явиться **синій пульсуючий маячок** — це ваше поточне місцезнаходження. Маячок оновлюється автоматично якщо ви рухаєтесь.

![Синій маячок локації користувача та панель «No data available»](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20173136.png)

### Крок 3 — Панель «Your area»

У **правому нижньому куті** з'являється панель зі статусом шуму у вашому районі:

| Стан панелі | Що означає |
|------------|-----------|
| «Click ⊕ to check the noise level near you» | Локація ще не надана |
| «No data available» | Локація визначена, але сенсори поруч відсутні або поза зоною покриття |
| Зелений — «У вас тихо» | < 45 дБ, тихо |
| Синій — «Шум помірний» | 45–55 дБ, норма |
| Жовтий — «Помітний шум» | 55–65 дБ |
| Оранжевий — «Гучно поруч» | 65–75 дБ |
| Червоний — «Небезпечний шум» | > 75 дБ |

Поруч зі статусом відображається точне значення в **дБ**.

Рівень визначається на основі сенсорів у радіусі **1.5 км** від вашої позиції — ближчі сенсори мають більший вплив на показник.

## 8. Сповіщення про загрози поруч

![Сповіщення UAV DETECTED — 3.9 км від вас](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20173149.png)

Якщо у вашому радіусі **4 км** з'являється новий інцидент — система автоматично показує спливаюче сповіщення у правому нижньому куті екрана.

### Що показує сповіщення

- **Тип загрози** — UAV DETECTED / ВИБУХ ЗАФІКСОВАНО / СИРЕНА / ГЕНЕРАТОР
- **Відстань від вас** — в кілометрах або метрах
- **Таймбар** зверху — відраховує 6 секунд до автоматичного закриття

### Умови появи сповіщення

1. Ви надали доступ до геолокації
2. Система виявила **новий** інцидент (не той що вже був при завантаженні)
3. Інцидент знаходиться в радіусі **4 км** від вас

Закрити вручну — кнопка **✕** у правому куті сповіщення.

> Кожен інцидент показується лише **один раз** — якщо та сама загроза оновиться, повторного сповіщення не буде.

## 10. Додаткові відомості

### Частота оновлення даних

| Що | Як часто |
|----|---------|
| Теплова карта загроз | Миттєво при появі нового інциденту |
| Карта шуму | Кожні 30 секунд |
| Ваш маячок на карті | Автоматично при переміщенні |
| Панель «Your area» | При кожному оновленні карти шуму |

### Конфіденційність

Ваші координати використовуються **лише локально** — для визначення відстані до загроз та сенсорів шуму. Координати не надсилаються на сервер.
