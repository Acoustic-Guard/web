## 1. Вхід до системи
Для отримання доступу до адміністративних функцій необхідно авторизуватись.

![Екран авторизації оператора](./img/Screenshot%202026-06-14%20101744.png)

**Кроки:**
1. Натисніть іконку замка 🔒 в нижній частині бічної навігаційної панелі.
2. У вікні що з'явиться введіть логін і пароль оператора.
3. Після успішного входу іконка замка замінюється на аватар з ініціалами вашого облікового запису.
4. Для виходу натисніть іконку `→` (LogOut) під аватаром.

> **Важливо:** Без авторизації система працює в режимі публічного перегляду — без маркерів інцидентів, теплової карти та Alert Feed.

## 2. Загальний огляд інтерфейсу
Інтерфейс складається з трьох основних зон:

![Загальний вигляд інтерфейсу системи з розміткою зон](./img/Screenshot%2026-06-14%102741.png)

* **Бічна навігаційна панель (зліва)**: Вертикальна панель з іконками для переходу між розділами:
  * 🗺 **Карта** — головна сторінка моніторингу в реальному часі.
  * 📊 **Аналітика** — графіки, статистика та експорт звітів.
  * ☰ **Мережа** — стан сенсорних вузлів.
* **Верхній заголовок**: Назва системи Acoustic Guard та підзаголовок Distributed Urban Acoustic Monitoring System.
* **Основна робоча область**: Змінюється залежно від обраного розділу.

## 3. Головна сторінка — Карта моніторингу
Це основний робочий екран оператора. Складається з блоку телеметрії вгорі та інтерактивної карти.

![Головна карта моніторингу в реальному часі](./img/Screenshot%2026-06-14%102741.png)

### 3.1 Блок телеметрії (верхня панель)
Три картки з ключовими показниками мережі в реальному часі:

![Блок віджетів телеметрії](./img/Screenshot%2026-06-14%102741.png)

| Картка | Що показує | Статуси |
| :--- | :--- | :--- |
| **Active Sensor Nodes** | Кількість активних сенсорів | NORMAL / WARNING / CRITICAL |
| **Avg. System Latency** | Середня затримка системи в мілісекундах | NORMAL / WARNING / CRITICAL |
| **Background Noise Level** | Фоновий рівень шуму в дБ | NORMAL / WARNING / CRITICAL |

### 3.2 Перемикачі шарів карти
Знаходяться у верхньому лівому куті карти.

**Теплова карта**
Кнопка «Теплова карта» (синя коли активна) — відображає інтенсивність загроз у вигляді теплового поля:
* 🔵 Синій — низька інтенсивність
* 🟢 Зелений — помірна
* 🟡 Жовтий — підвищена
* 🟠 Оранжевий — висока
* 🔴 Червоний — критична

![Теплова карта](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095701.png)

*Теплова карта об'єднує всі активні інциденти в єдине поле — чим більше інцидентів в одній зоні і чим вища їх впевненість, тим яскравіший колір.*

**Карта шуму**
Кнопка «Карта шуму» (фіолетова коли активна) — відображає гексагональну сітку рівнів акустичного шуму по Дарницькому району:
* 🟢 Зелений — менше 45 дБ (тиша)
* 🔵 Синій — 45–55 дБ (норма)
* 🟡 Жовтий — 55–65 дБ (помітно)
* 🟠 Оранжевий — 65–75 дБ (гучно)
* 🔴 Червоний — більше 75 дБ (небезпека)

![Карта шуму](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20102802.png)

*Дані надходять з публічного API кожні 30 секунд. Кольори між зонами плавно переходять один в одний завдяки IDW-інтерполяції. Обидва шари можна вимкнути повторним натисканням кнопки.*

### 3.3 Маркери інцидентів на карті
Активні інциденти відображаються як кольорові пульсуючі точки:

![Приклад відображення маркерів на карті](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20102741.png)

| Колір | Тип загрози |
| :--- | :--- |
| 🟣 Фіолетовий | БПЛА (UAV) |
| 🔴 Червоний | Вибух (Explosion) |
| 🟠 Бурштиновий | Сирена (Siren) |
| 🔵 Синій | Генератор (Generator) |
| 🔵 Синій | Вантажівка (Truck) |

*Натисніть на маркер щоб відкрити панель деталей інциденту.*

### 3.4 Панель деталей інциденту
З'являється у верхньому правому куті після кліку на маркер.

![Панель деталей конкретного інциденту](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095727.png)

Містить:
* **Тип загрози** — назва та кольоровий індикатор
* **ID** — скорочений ідентифікатор інциденту
* **Рівень довіри** — відсоток впевненості системи у визначенні загрози
* **Широта та Довгота** — точні координати з точністю до 6 знаків

**Позначити як Вирішено:**
Кнопка «Позначити як Вирішено» (зелена) закриває інцидент. Натисніть кнопку -> Під час обробки з'являється напис «Закриття...» -> Після успіху маркер зникає з карти і теплової карти -> Панель закривається автоматично.
*Для закриття панелі без вирішення — натисніть кнопку `✕` у верхньому правому куті панелі.*

### 3.5 Панель статистики інцидентів (Drawer)
Виїзна панель з правого краю карти. Відкривається натисканням іконки 📊 (вертикальна смужка з графіком) на правому краю.

![Виїзна панель статистики інцидентів](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20103402.png)

Містить:
* Загальна кількість активних інцидентів з червоним індикатором
* Середня впевненість по всіх інцидентах
* 4 картки по типах (БПЛА / Вибухи / Сирени / Генератори) з лічильником та прогрес-баром що показує частку кожного типу

*Закрити панель — кнопка `›` у верхньому правому куті панелі або повторне натискання іконки.*

### 3.6 Керування картою (правий куток)
Вертикальна група кнопок у верхньому правому куті:

![Елементи керування зумом та темою](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095748.png)

| Кнопка | Дія |
| :--- | :--- |
| `+` | Збільшити масштаб |
| `-` | Зменшити масштаб |
| `☀` / `🌙` | Перемикання між темною та світлою темою карти |

* **Темна тема** (за замовчуванням) — картографічна підкладка CartoDB Dark Matter, оптимальна для нічної роботи та відображення теплової карти.
* **Світла тема** — підкладка CartoDB Voyager, краще підходить для денного використання та роботи з картою шуму.

### 3.7 Alert Feed (права панель)
Стрічка сповіщень в реальному часі праворуч від карти.

![Панель Alert Feed зі стрічкою подій](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095701.png)

Кожна картка містить:
* **Тип загрози** — кольоровий бейдж
* **Відсоток впевненості** — праворуч від бейджа
* **Координати** — географічне положення інциденту
* **Час** — момент фіксації

*Стрічка оновлюється автоматично через WebSocket. Індикатор `● Live` у заголовку підтверджує активне з'єднання. Нові сповіщення додаються зверху.*

### 3.8 Легенда карти
Знаходиться у нижньому лівому куті карти. 

![Легенда карти для інцидентів та шуму](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095701.png)

Показує відповідність кольорів типам загроз (або рівням шуму при активній карті шуму). Не інтерактивна.

## 4. Сторінка аналітики
Перейдіть через іконку 📊 в бічній навігації.

![Загальний вигляд сторінки аналітики](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095812.png)

### 4.1 Фільтри часового діапазону
Кнопки у верхній частині сторінки:

![Фільтри вибору часу](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095831.png)

| Кнопка | Діапазон |
| :--- | :--- |
| **Last 24 hours** | Останні 24 години |
| **Last 7 days** | Останні 7 днів |
| **Last 30 days** | Останні 30 днів |
| **Custom Range** | Довільний діапазон |

*При виборі Custom Range з'являються два поля для введення дат у форматі дд.мм.рррр. Після заповнення натисніть Go для застосування фільтру. Активна кнопка підсвічується синім. Всі графіки та таблиця оновлюються відповідно до обраного діапазону.*

### 4.2 Картки статистики
Чотири картки у верхній частині дашборду:

![Картки загальної статистики](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095812.png)

| Картка | Що показує |
| :--- | :--- |
| **Total Incidents** | Загальна кількість інцидентів за обраний період |
| **Most Frequent** | Найчастіший тип загрози та кількість його фіксацій |
| **Avg Confidence** | Середній рівень впевненості системи у відсотках |
| **Critical Events** | Кількість інцидентів з впевненістю понад 90% |

### 4.3 Графік частоти загроз (Threat Frequency Over Time)
Лінійний графік що показує динаміку появи різних типів загроз у часі.

![Лінійний графік частоти загроз](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095831.png)

* Кожна лінія відповідає типу загрози (UAV — фіолетовий, Explosion — червоний, Siren — бурштиновий, Generator — синій, Truck — синій).
* Вісь X — часова шкала.
* Вісь Y — кількість інцидентів.
* При наведенні курсора на графік з'являється tooltip з точними значеннями для кожного типу в даний момент часу.

### 4.4 Розподіл загроз (Threat Distribution)
Кругова діаграма (Doughnut) праворуч від лінійного графіка.

![Кругова діаграма розподілу](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095831.png)

Показує відсоткове співвідношення типів загроз за обраний період. Під діаграмою розташована легенда з кількістю кожного типу. При наведенні на сектор з'являється підказка.

### 4.5 Таблиця Historical Incidents
Таблиця всіх зафіксованих інцидентів за обраний період.

![Таблиця історії інцидентів](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095848.png)

Стовпці:
* **Date/Time** — дата і час фіксації у форматі дд.мм.рррр, гг:хх:сс
* **Threat Type** — тип загрози у вигляді кольорового бейджа
* **Coordinates** — координати у форматі широта, довгота
* **Confidence** — рівень впевненості у відсотках
* **Status** — статус інциденту (Confirmed червоним / Resolved зеленим / Investigating жовтим)

*У правому верхньому куті таблиці відображається загальна кількість записів.*

### 4.6 Експорт PDF звіту
Кнопка «Export PDF Report» у верхньому правому куті сторінки.

![Кнопка експорту PDF](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095908.png)

Формує та відкриває діалог друку браузера з попередньо підготовленим звітом що містить:
* Заголовок з датою та статусом
* Чотири картки зведеної статистики
* Повну таблицю інцидентів з усіма полями

*Для збереження як PDF оберіть принтер «Microsoft Print to PDF» (або аналог у вашому браузері) та натисніть «Друк». Якщо за обраний період немає даних — система виведе попередження і експорт не запуститься.*

## 5. Сторінка мережі сенсорів
Перейдіть через іконку ☰ (три горизонтальні смужки) в бічній навігації.

![Сторінка стану мережі сенсорів](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095928.png)

### 5.1 Картки стану мережі
Чотири картки у верхній частині:

![Картки статусу мережі та брокера](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095928.png)

| Картка | Що показує |
| :--- | :--- |
| **Connected Nodes** | Кількість онлайн-вузлів (зелений колір) |
| **Offline Nodes** | Кількість недоступних вузлів (червоний колір) |
| **System Load** | Поточне навантаження на систему у відсотках |
| **Broker Status** | Стан брокера повідомлень (Healthy / Degraded / Down) |

### 5.2 Таблиця вузлів
Список всіх сенсорних вузлів мережі.

![Таблиця списку вузлів](https://github.com/Acoustic-Guard/web/blob/main/img/Screenshot%202026-06-14%20095928.png)

Стовпці:
* **NODE ID** — ідентифікатор вузла (формат AG-NODE-XXX)
* **LOCATION** — район розташування сенсора
* **STATUS** — поточний стан вузла:
  * 🟢 **ONLINE** — вузол працює нормально
  * 🔴 **OFFLINE** — вузол недоступний
  * 🟡 **WARNING** — вузол працює з відхиленнями
* **LATENCY** — затримка відповіді вузла в мілісекундах
* **LAST HEARTBEAT** — час останнього сигналу від вузла

*Дані оновлюються автоматично. При появі вузла зі статусом OFFLINE або WARNING рекомендується перевірити фізичний стан обладнання.*

## Додаткові відомості

**Автоматичне оновлення даних**
* Інциденти на карті та Alert Feed — миттєво через WebSocket
* Телеметрія — в реальному часі
* Карта шуму — кожні 30 секунд
* Аналітика — кожні 30 секунд

**Сесія та безпека**
При закінченні терміну дії токену система автоматично виходить з облікового запису і перенаправляє на головну сторінку. Рекомендується не залишати авторизовану сесію без нагляду.
